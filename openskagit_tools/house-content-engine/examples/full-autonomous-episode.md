# Example: Full Autonomous Episode Request

User intent:

> Find an interesting Washington homeowner question involving detached shops, investigate whether available property data can tell us anything useful, and produce the strongest justified video package.

Expected behavior:

1. Read Discovery Guide + Workflow.
2. Inspect available property-data capabilities.
3. Generate candidate shop-related investigations rather than assuming “shops add value.”
4. Feasibility-check available shop/sales/acreage/size/location fields.
5. Select the strongest question.
6. Read Research & Verification and conduct the analysis.
7. If the data cannot support a useful conclusion, reframe or return to Discovery.
8. Build the fact ledger and prohibited-claims list.
9. Read Story Development and create the central reveal, scripts, visual beats, and source package.
10. Generate only approved visuals.
11. Generate narration from the approved script and use real timing.
12. Build/render the appropriate formats.
13. Inspect final media and compare all data-bearing content to the ledger.
14. Return a completed production package or a clear block/caveat.

The skill should be willing to discover that acreage, house size, or neighborhood explains much of the raw difference and should not claim a fixed shop contribution without evidence.
